# 🚀 Actividad 8: Algoritmos Voraces (Greedy)

Este repositorio contiene el desarrollo integral de la **Actividad 8** para la asignatura de **Teoría de la Computación** del programa profesional de **Ingeniería de Software** de la **Universidad La Salle**. 

El presente documento consolida la base teórica, la explicación detallada de las estrategias ávidas, el análisis de complejidad asintótica Big O y las implementaciones de software para los problemas planteados.
